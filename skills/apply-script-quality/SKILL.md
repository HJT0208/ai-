# 小G·优秀脚本标准

把文档结构转化为创作步骤和有文本依据的检查，不照抄案例、不把启发当保证。使用 [六层标准与适配](references/quality-framework.md)，必要时核对 `assets/source-document.txt` 与 `assets/source.json`。

## 输入与边界

读取当前目标、受众、商品事实、题材、时长、锁定剧情、素材及修改范围。调用人物资源库检索旧人物、图片和剧本，明确复用方式，再由主技能统筹。默认中文、40+受众、无品牌、无配乐、每30秒组/5秒段；本项目明确要求优先。不固定夫妻、复仇、美妆或情感反转。

## 按原文六层结构创作和检查

1. **目标与开场**：用一句话明确目的和观众；通过可见冲突、悬念或共鸣建立关注点。CID优先黄金3/5秒让观众看懂，不先花30秒解释背景。
2. **叙事与节奏**：选三幕、问题解决或适用结构；写需求→阻碍→行动→可观察结果。转折有依据，情绪反应与缓冲占真实时间，每5秒段一个核心事件。
3. **人物与情感**：人物有差异化行为/说话方式与行动动机；通过视线、眉眼、唇、肩颈、重心及道具互动递进情绪，减少解释内心和夸张口号。人物身份与造型引用已选资源版。
4. **台词与画面**：台词符合具体经历与情境，少而准；动作能表达就不重复解释。色调、景别、构图与运镜服务叙事，不把冷暖机械等同情绪，不强加金句或反转。
5. **可执行性**：按用户ComfyUI素材需求标场景、景别、机位/运镜、动作顺序、台词、时间、道具、首末态与参考图用途。分清5秒生成段和摄影镜头，不照搬文档“1分钟15—20镜/每镜3—4秒”。口播时长需实际试读；模型时点不作精确保证。
6. **案例归纳与自检**：提取铺垫、转折、细节及商品出现理由，回查目标清楚、叙事抓人、情感可信、表达精炼、细节可执行。案例中的关系、商品功能、数据与疗效不是当前项目事实。

## 接入通用工作流

- 开写前给一句话目标、受众、开场关注点、结构和人物动机；资源库给可用人物/图像ID。
- 写作时由DeepWhite编剧维护因果对白，DeepSeek方法辅助钩子卖点，MadStory落实分镜，图像技能与真实图像工具完成图片。本技能提供质量标准，不让各技能重复重写整剧。
- 交付前按六层标准标通过/需修改/待验证，每项引用句子、段号或时间段。问题给位置、影响、最小修改和前后承接；不捏造科学评分、爆款概率或实测效果。
- 纯台词、画面剧情、声音表演说明、整合提示词分区；静音段台词为空，时间/图号/情绪不进入朗读输入。真实误读、口型和音色待用户ComfyUI成片反馈，规则不能保证模型输出。
- 人物使用资源库的已选面部锁定卡，换装/表情不自动换脸。声音只列当前项目已获准的事件，不因家庭写实、喜剧或道具互动自行增加摩擦声、脚步声、呼吸或其他声效。
- 只改用户授权内容，保留确认剧情与商品证据；自检后将实质新版本登记资源库，在用户指定验收点交审，不机械逐步求批准。

仅交当前任务要求的剧本、图片或提示词；广告视频由用户自己的ComfyUI生成，不连接算力或操作队列。
