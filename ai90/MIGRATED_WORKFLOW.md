# 从「ai广告短漫剧制作」迁移的工作流记录

来源对话：6ad752e2-07b8-83e8-bf5b-5029849de688（依据当前可见缓存预览）

## 已确认约束

- 90秒广告短漫剧：18个5秒片段，分为3组×30秒。
- 每段详细稿约2000字以上（原对话记录显示约3057—3406汉字）。
- 16张独立参考图与逐段 Picture 槽位；当前运行器保留工作流图片占位符。
- 详细提示词、视觉执行稿、纯台词、声音说明分开保存。
- 全片禁止配乐；静音段台词为空。
- “女主使用完洗面奶前脸上保持痘痘，冲净后才出现无痘剧情特效”是该历史项目的专属事实，不能自动套用到新商品。
- 实际视频当时尚未生成，网页发布不等于 ComfyUI 成片验收。

## 当前已接入的技能

- produce-cid-ad-drama：主流程、30秒组/5秒段、素材槽位和交付。
- manage-drama-resources：人物面部锁定、服装版本、资源登记。
- apply-script-quality：六层脚本质量检查。
- deepwhite-screenwriting-v1：中文剧情、因果和悬念。
- deepseek-video-script：短视频钩子和结构化口播（仅在本机配置 API 时调用）。
- mad-story：分镜、表演、空间和运镜提示词。
- deepwhite-image-prompt-builder：静态人物、场景和商品参考图提示词。

技能说明已保存到本项目 `skills/` 目录，运行器位于 `ai90/run_pipeline.py`。

## ComfyUI 交接

真实可执行的 API workflow JSON 仍需从原对话的附件或 ComfyUI 导出文件取得；缓存预览没有包含附件内容。当前运行器不会伪造或猜测节点图，只接受用户提供的 API 格式 JSON，并替换 `{{PROMPT}}` 与 `{{IMAGE}}`。运行时只查询历史，不取消或删除任务。
